# Muhammad Sufyan (Sufii) — Modern Portfolio Website

> **Frontend Developer & Visual Designer**  
> *Minimalist Cyberpunk / Editorial Dark Mode Portfolio*

Built with **Next.js 14 (App Router)**, **Tailwind CSS**, **TypeScript**, and **Framer Motion**.

---

## ⚡ Highlights & Key Features

### 1. Hero with Anti-Gravity Animation
- **Zero-G Physics Simulator**: Interactive tech-stack pills (`React`, `Next.js`, `TypeScript`, `Tailwind CSS`, `Groq API`, `Photoshop`, `Framer Motion`) floating with infinite organic motion.
- **Draggable & Deflecting**: Grab and toss any pill across the viewport with spring damping (`drag`, `dragElastic`, `bounceStiffness`).
- **Interactive Zero-G Shockwave**: A dedicated trigger button that explodes the gravity field and lets pills gracefully re-stabilize.
- **Synthesized Web Audio Feedback**: Integrated audio cues generated mathematically via the browser's Web Audio API (zero external asset requests).

### 2. Dual Focus About Section
- **Two-Column Editorial Grid**:
  - **Column 01 (Frontend Engineering)**: Component modularity, clean architecture, edge optimization, Core Web Vitals, and streaming AI pipelines.
  - **Column 02 (Visual Design & Identity)**: Editorial typography, automotive & streetwear aesthetics (`@sufii.raw`), and commercial digital design systems (`CreativeVibeAssets`).
- **Live Capability Specs**: Metric badges covering Lighthouse performance targets, asset kit volume, and strict type safety.

### 3. Featured Projects Showcase
1. **ATS Resume Tailor**:
   - Sub-second AI resume-to-job optimization powered by Groq LPUs (`< 380ms` latency).
   - Embedded interactive keyword matching sandbox with real-time scoring.
2. **Interactive Storybook & Motion Web Apps**:
   - Gestural storytelling with Framer Motion, canvas shaders, and spatial Web Audio synthesizers.
   - Live clickable multi-node audio synthesizer simulator.
3. **Digital Assets Ecosystem (CreativeVibeAssets)**:
   - High-conversion storefront delivering streetwear graphic kits, Japanese typography packs, and PSD assets.

### 4. Editorial Design Gallery Teaser (@sufii.raw)
- Curated poster artworks showcasing automotive series (Skyline R34, Porsche 911 Luftgekühlt) and streetwear posters (Neo-Shibuya, Kinetic Type).
- Category filtering (`All`, `Automotive`, `Streetwear`, `Editorial Type`, `Cyberpunk`).
- **Interactive Lightbox Spec Sheet**: Inspect each poster's toolchain, typefaces (Druk Wide, Neue Haas Grotesk, Akira), and print specs.
- Direct links to [`@sufii.raw`](https://instagram.com/sufii.raw).

### 5. Transmission Terminal & System Footer
- Copy-to-clipboard email pill with instant visual feedback and audio click.
- Interactive dispatch form with field validation and transmission confirmation.
- Live real-time clock telemetry (local time & UTC).
- Links to GitHub (`muhammad-sufiyan`), Instagram (`@sufii.raw`), and email.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server & Client Components)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Cyberpunk dark palette `#0a0a0a`, custom scanlines, glows)
- **Animation**: [Framer Motion](https://www.framer.com/motion/) (Floating physics, drag constraints, lightbox modals)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict type checking)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio Engine**: Native HTML5 Web Audio API Synthesizer

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm 10+

### Installation & Run

```bash
# Navigate to the project directory
cd C:\Users\muham\.gemini\antigravity\scratch\sufiyan-portfolio

# Start development server
npm run dev

# Or build and launch the production server
npm run build
npm run start -p 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
